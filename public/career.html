Tech Role Descriptions

Frontend Developer
Builds what users see and interact with. Works with HTML, CSS, JavaScript, and frameworks like React to create fluid user experiences.
Backend Developer
Builds server logic, RESTful APIs, and databases. Uses Node.js, Python, or Java to power business logic and high-throughput data transactions.
Full Stack Developer
Works on both client-side interfaces and backend server architecture. Masters the entire web lifecycle from browser rendering to cloud database storage.
Data Analyst
Cleans, aggregates, analyses, and visualises data to help organizations make strategic decisions using SQL, Excel, and Python.
Machine Learning Engineer
Builds, trains, and evaluates intelligent predictive models using Python, Scikit-learn, TensorFlow, or PyTorch.
UI/UX Designer
Researches user needs, designs interfaces, prototypes user journeys, and ensures digital accessibility using tools like Figma.

Universal Skills Every Tech Professional Needs:

  • Version Control (Git & GitHub)
  • Command Line / Terminal proficiency
  • Problem-solving & Debugging discipline
  • Technical Documentation & Research skills
  • Cross-functional communication & collaboration
